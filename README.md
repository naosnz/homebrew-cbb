# Naosnz Cbb

## How do I install these formulae?

`brew install naosnz/cbb/<formula>`

Or `brew tap naosnz/cbb` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "naosnz/cbb"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
